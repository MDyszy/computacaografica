AJUDA

Geral:
P          Alterna a projeção ativa (5 tipos disponíveis)
ESC        Encerra a aplicação
F1         Abre / fecha esta ajuda

Seleção de objetos:
TAB        Avança para o próximo objeto
SHIFT+TAB  Volta para o objeto anterior
           (objeto selecionado aparece em vermelho)

Escala (aplicada ao objeto selecionado):
Eixo X:   A aumenta   /   Z diminui
Eixo Y:   S aumenta   /   X diminui
Eixo Z:   D aumenta   /   C diminui

Rotação (aplicada ao objeto selecionado):
Eixo X:   F aumenta   /   V diminui
Eixo Y:   G aumenta   /   B diminui
Eixo Z:   H aumenta   /   N diminui

Translação (aplicada ao objeto selecionado):
Eixo X:   J aumenta   /   M diminui
Eixo Y:   K aumenta   /   , diminui
Eixo Z:   L aumenta   /   . diminui

Zoom:
+          Aumenta o zoom
-          Diminui o zoom
0          Restaura o zoom inicial
Pressione F1 para fechar
